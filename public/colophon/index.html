What this is built from, who made the parts, and the licences they are under.

The software

Open source under the MIT licence, which means you can read it, run your own copy, and change it. The source is at github.com/Suvir0/sonos-scrobbler, and reading it is the only way to actually check the claims on the privacy page — that there is no history table is a fact about the schema, not a promise.

It runs on Cloudflare Workers with D1 for the account records and Durable Objects for the playing-right-now state, which is why there is nothing to install and nothing running at home.

The typefaces

Archivo by Omnibus-Type sets the headings and the body; IBM Plex Mono sets the labels and the readings. Both are under the SIL Open Font License 1.1 — Archivo's licence and IBM Plex Mono's licence ship with them, as that licence requires.

They are served from this domain rather than from a font CDN. A webfont request carries your IP address and the page you are reading to whoever answers it, and the privacy page says no page here makes a third-party request. That has to be true of fonts too.

Who this talks to

  • Sonos, whose cloud sends this service an event when your playback changes. Sonos is a trademark of Sonos, Inc. This project is not affiliated with, endorsed by, or sponsored by them.
  • Last.fm and ListenBrainz, which receive the plays — but only the ones you connected an account for. Their trademarks are their own.

Nothing else. No analytics, no advertising, no error-reporting service, no embedded anything. The content security policy this site sends forbids loading a script, stylesheet or image from anywhere but here, so that is enforced rather than promised.

Reporting a problem

A security problem — anything that could expose somebody's credentials — goes to hello@suvir.net rather than a public issue. See the security policy. Anything else is welcome as a GitHub issue.

No warranty

The MIT licence disclaims warranties and liability, and the terms say the same in plainer words: this is offered as is, it depends on three services that can change or stop, and a play that happens during an outage is not recoverable. It is a small project run by one person.
